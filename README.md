# Stock Watchlist ของฉัน

แอปดูราคาหุ้นส่วนตัว เปิดดูได้ที่ **https://mornavapon.github.io/stock/**
(ติดตั้งเป็นแอปบนแท็บเล็ตและมือถือด้วย Chrome → ⋮ → **Install app**)

ไฟล์นี้คือคู่มือ เปิดอ่านได้ที่หน้าแรกของ repo นี้เสมอ

## 0. ภาพรวมแบบสั้น

```
Yahoo Finance  →  GitHub (ดึงราคาทุก 10 นาที)  →  prices.json  →  หน้าแอป
                                                     ↘ ส่งแจ้งเตือนเข้าแอป ntfy (08:00, 12:50, 20:00)
```

| ไฟล์ | ทำหน้าที่ | แก้บ่อยไหม |
|---|---|---|
| `tickers.json` | **รายชื่อหุ้นและกรอบ** ทั้งหมด | แก้บ่อย |
| `index.html` | หน้าตาแอป | นานๆ ครั้ง |
| `prices.json` | ราคาล่าสุด (ระบบเขียนเอง) | **ห้ามแก้** |
| `fetch_prices.py` | โปรแกรมดึงราคาจาก Yahoo | ไม่ต้องแก้ |
| `notify.py` | โปรแกรมสรุปหุ้นขึ้นแรง/ลงแรงแล้วส่งแจ้งเตือน | นานๆ ครั้ง |
| `.github/workflows/update.yml` | สั่งดึงราคาทุก 10 นาที | ไม่ต้องแก้ |
| `.github/workflows/notify.yml` | ตั้งเวลาแจ้งเตือน 08:00 / 12:50 / 20:00 | นานๆ ครั้ง |
| `manifest.json`, `icon-*.png` | ไอคอนและชื่อแอป | ไม่ต้องแก้ |

## วิธีแก้ไฟล์ใน GitHub (ใช้ทุกครั้ง)

1. เปิด `github.com/mornavapon/stock`
2. กดชื่อไฟล์ที่ต้องการแก้
3. กดรูป **ดินสอ** (Edit) มุมขวาบนของไฟล์
4. แก้ข้อความ (หรือกดในช่อง → Select all → Paste ทับทั้งไฟล์ เมื่อได้ไฟล์ใหม่ทั้งชุดมา)
5. กด **Commit changes** (ปุ่มเขียวมุมขวาบน) แล้วกด **Commit changes** อีกครั้งในหน้าต่างที่เด้ง
6. รอราคารอบถัดไป (ไม่เกิน 10 นาที) หรือสั่งเอง: แท็บ **Actions** → **update-prices** → **Run workflow** → ปุ่มเขียว แล้วเปิดแอปกดรีเฟรช ↻

> ถ้าพิมพ์ผิดแล้วแอปขึ้น "โหลดรายชื่อหุ้นไม่สำเร็จ" แปลว่าไฟล์ `tickers.json` มีเครื่องหมายขาดหรือเกิน (ดูหัวข้อแก้ปัญหา) แก้กลับได้เสมอ ไม่เสียหายถาวร

## 1. เพิ่ม / ลบ / สลับหุ้นใน watchlist

แก้ที่ไฟล์ **`tickers.json`** แต่ละกรอบมีรายชื่อหุ้นอยู่ในวงเล็บเหลี่ยม `[ ]`

```json
{ "name": "คริปโต", "symbols": ["BTC-USD", "ETH-USD"] },
```

**เพิ่มหุ้น:** พิมพ์ต่อท้ายในวงเล็บ ใส่เครื่องหมายคำพูดและลูกน้ำคั่น

```json
{ "name": "คริปโต", "symbols": ["BTC-USD", "ETH-USD", "SOL-USD"] },
```

**ลบหุ้น:** ลบทั้งก้อนของตัวนั้น รวมเครื่องหมายคำพูด และลูกน้ำที่ติดกัน
**สลับลำดับ:** ย้ายตำแหน่งในวงเล็บ (แอปแสดงตามลำดับในไฟล์ ยกเว้นเมื่อกดปุ่ม "เรียงตาม %")

**กฎสำคัญของไฟล์นี้**
- ชื่อหุ้นทุกตัวต้องอยู่ใน `"..."` และมี `,` คั่นระหว่างตัว **ยกเว้นตัวสุดท้ายของวงเล็บ ห้ามมีลูกน้ำต่อท้าย**
- ใช้ตัวอักษรภาษาอังกฤษพิมพ์ตรงๆ ไม่เว้นวรรคในชื่อหุ้น

**รหัสหุ้นตามตลาด (ใช้ของ Yahoo Finance)**

| ตลาด | รูปแบบ | ตัวอย่าง |
|---|---|---|
| หุ้นไทย | ชื่อ + `.BK` | `PTT.BK`, `AOT.BK` |
| ดัชนีไทย | `^SET.BK` | |
| หุ้นสหรัฐ / ETF | ชื่อตรงๆ | `AAPL`, `VOO`, `XLK` |
| ดัชนี | ขึ้นต้น `^` | `^GSPC`, `^N225`, `^TWII` |
| เกาหลี | `.KS` | `005930.KS` |
| ฮ่องกง | `.HK` | `2828.HK` |
| เวียดนาม | `.VN` | `FUEVFVND.VN` |
| จีน เซินเจิ้น / เซี่ยงไฮ้ | `.SZ` / `.SS` | `300750.SZ`, `000001.SS` |
| ญี่ปุ่น | `.T` | `7203.T` |
| ฟิวเจอร์ส (น้ำมัน ทอง แก๊ส) | ลงท้าย `=F` | `BZ=F`, `GC=F` |
| ค่าเงิน | ลงท้าย `=X` | `THB=X` |
| คริปโต | `-USD` | `BTC-USD` |

**ตรวจว่ารหัสถูกไหม:** ถ้าหุ้นตัวไหนไม่ขึ้นราคา (ขึ้น "—") บรรทัดเล็กๆ ล่างสุดของแอปจะเขียนว่า **"ไม่พบราคา: ..."** พร้อมชื่อตัวนั้น แปลว่ารหัสผิดหรือ Yahoo ไม่มีข้อมูล ลองค้นรหัสที่ finance.yahoo.com

## 2. เพิ่ม / ย้ายกรอบ (หน้าต่างย่อย)

แต่ละกรอบคือก้อน `{ ... }` ใน `tickers.json` ตัวเลือกที่ใส่ได้:

| ชื่อ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `"name"` | ชื่อกรอบ (บังคับ) | `"name": "คริปโต"` |
| `"symbols"` | รายชื่อหุ้น (บังคับ) | `"symbols": ["BTC-USD"]` |
| `"col"` | **แท็บเล็ต:** อยู่คอลัมน์ที่เท่าไร (1 ซ้าย, 2 กลาง, 3 ขวา) **มือถือ:** ใช้กำหนดลำดับบนลงล่างภายในหน้า (เลขน้อยขึ้นก่อน) | `"col": 2` |
| `"page"` | **แท็บเล็ตและมือถือ:** อยู่หน้าไหน (ปัดซ้าย-ขวา) ไม่ใส่ = หน้า 1 | `"page": 2` |
| `"phoneRows"` | **มือถือ:** แสดงกี่แถวแล้วเลื่อนนิ้วดูที่เหลือ | `"phoneRows": 20` |
| `"tabletRows"` | **แท็บเล็ต:** แสดงกี่แถวแล้วเลื่อนนิ้วดูที่เหลือ | `"tabletRows": 14` |
| `"notify"` | เข้ารอบแจ้งเตือนไหน (`"am"` = สหรัฐ 08:00, `"pm"` = เอเชีย 20:00) | `"notify": "am"` |

ตัวอย่างกรอบใหม่ไว้หน้า 2 คอลัมน์ 3 และให้แจ้งเตือนรอบสหรัฐ:

```json
{
  "name": "หุ้นเทคใหม่",
  "page": 2,
  "col": 3,
  "notify": "am",
  "symbols": ["NVDA", "AMD", "AVGO"]
}
```

**เรื่องที่ต้องจำ**
- ลำดับของกรอบบน **มือถือ** เรียงตามลำดับในไฟล์จากบนลงล่าง
- กรอบใหม่ที่ไม่ได้ใส่ `"col"` จะไปอยู่คอลัมน์ 1 ของแท็บเล็ต ควรใส่ `"col"` เสมอ
- ระหว่าง `{ }` แต่ละกรอบ ต้องมี `,` คั่น (ยกเว้นกรอบสุดท้าย)
- การสลับหน้า (ปัดซ้าย-ขวา) ใช้ได้ทั้ง **แท็บเล็ตแนวนอน** และ **มือถือ** (จอขนาดกลางระหว่างสองแบบนี้ กรอบจะเรียงต่อกันเลื่อนลง)
- บนมือถือ แต่ละหน้าเลื่อนขึ้น-ลงได้ ลำดับกรอบในหน้าเรียงตามเลข `"col"` ก่อน แล้วตามลำดับในไฟล์

### ผังหน้าจอตอนนี้ (กรอบเลข 1-11)

| เลข | กรอบ | หน้า | คอลัมน์ |
|---|---|---|---|
| 1 | ดัชนีไทย (^SET.BK) | 1 | 1 |
| 2 | หุ้นไทย 1 | 1 | 1 |
| 3 | หุ้นไทย 2 | 1 | 2 |
| 4 | ETF เวียดนามและฮ่องกง | 1 | 2 |
| 5 | น้ำมัน ทอง แก๊ส | 1 | 2 |
| 6 | ค่าเงินบาท | 1 | 2 |
| 7 | คริปโต | 1 | 2 |
| 11 | ดัชนีหุ้นเอเชีย | 1 | 3 |
| 8 | ดัชนีสหรัฐ | 2 | 1 |
| 9 | หุ้นสหรัฐ | 2 | 1 |
| 10 | Sector หุ้นสหรัฐ | 2 | 2 |

- **แท็บเล็ต:** หน้า 1 มี 3 คอลัมน์ (1 และ 2 | 3 ถึง 7 | 11) ปัดไปหน้า 2 เจอ 8 และ 9 ทางซ้าย 10 ทางขวา
- **มือถือ:** หน้า 1 เรียง 1, 2, 3, 4, 5, 6, 7, 11 ปัดไปหน้า 2 เจอ 8, 9, 10 (หุ้นสหรัฐทั้งหมด)
- ย้ายกรอบไปที่อื่นแค่แก้ `"page"` กับ `"col"` ของกรอบนั้น และลำดับกรอบในไฟล์ไม่ต้องตรงกับหน้าจอ

## 3. ปรับความยาวของกรอบ (จำนวนแถวที่เห็น)

**วิธีที่ง่ายที่สุด:** ใส่ `"phoneRows"` (มือถือ) หรือ `"tabletRows"` (แท็บเล็ต) ในกรอบนั้นที่ **`tickers.json`** ไม่ต้องแตะไฟล์อื่น

```json
{ "name": "หุ้นไทย 2", "tabletRows": 14, "phoneRows": 10, "notify": "pm", "symbols": [ ... ] }
```

- ตัวเลขคือ "จำนวนแถวที่เห็นก่อนเลื่อนนิ้ว" แถวที่เหลือเลื่อนดูในกรอบนั้น
- ถ้าไม่ใส่อะไรเลย แต่ละกรอบสูงสุด 28 แถว
- ตัวอย่างในแท็บเล็ต: หุ้นไทย 2 ตั้งไว้ 10 แถว ถ้าอยากเห็นมากขึ้น ใส่ `"tabletRows": 14` ในกรอบนั้น

**ค่าที่ตั้งไว้ตอนนี้ (อยู่ในไฟล์ `index.html`)** ค่าใน `tickers.json` จะชนะค่าตรงนี้เสมอ

| กรอบ | มือถือ | แท็บเล็ต |
|---|---|---|
| หุ้นไทย 2 | 10 แถว | 10 แถว |
| หุ้นสหรัฐ | 20 แถว | อัตโนมัติ (ตามความสูงจอ) |
| กรอบอื่น | สูงสุด 28 | อัตโนมัติ (ตามความสูงจอ) |

**ถ้าอยากแก้ในไฟล์ `index.html` โดยตรง** หาสองบรรทัดนี้ (ตอนกดไฟล์ จะอยู่ราวบรรทัดที่ 136 และ 138) แล้วแก้ตัวเลข

```js
var PHONE_ROWS = { "หุ้นไทย 2": 10, "หุ้นสหรัฐ": 20 };
var TABLET_ROWS = { "หุ้นไทย 2": 10 };
```

**ข้อควรระวัง:** บนแท็บเล็ต คอลัมน์ที่มีหลายกรอบ ถ้าตั้งจำนวนแถวของกรอบใดมากเกินไป ความสูงรวมของคอลัมน์อาจเกินจอ (เช่นคอลัมน์กลางตอนนี้มี หุ้นไทย 2, ETF, น้ำมันทอง, ค่าเงินบาท, คริปโต) ถ้าสังเกตว่ากรอบล่างสุดหลุดจอ ให้ลดจำนวนแถวลง

## 4. แจ้งเตือนตัวขึ้นแรง / ลงแรง (ntfy)

**ทำงานอย่างไร:** วันละ 3 รอบ ระบบสรุปหุ้นที่ **ขึ้นแรง 3 ตัว และลงแรง 3 ตัว ของแต่ละกรอบ** (กรอบที่มีหุ้นน้อยจะลดเหลือ 2 หรือ 1 ตัวอัตโนมัติ) แล้วส่งเข้าแอป ntfy บนทุกเครื่องที่สมัครช่องไว้

| เวลา (ไทย) | สรุปอะไร |
|---|---|
| 08:00 | ตลาดสหรัฐปิด (กรอบที่ตั้ง `"notify": "am"`) |
| 12:50 | หุ้นไทย (.BK) หลังปิดภาคเช้า (กรอบ หุ้นไทย 1 และ 2) |
| 20:00 | ตลาดเอเชียและหุ้นไทยปิด (กรอบที่ตั้ง `"notify": "pm"` รวมทั้งหุ้นเอเชียที่ปนอยู่ในกรอบหุ้นสหรัฐ เช่น `005930.KS`) |

- วันหยุดตลาดหรือเสาร์-อาทิตย์ ระบบจะไม่ส่ง (ข้ามหุ้นที่ข้อมูลเก่ากว่า 14 ชั่วโมง)
- GitHub อาจส่งช้ากว่ากำหนด 5-30 นาที เป็นเรื่องปกติ
- เพิ่มหรือลบหุ้นใน `tickers.json` แล้วการแจ้งเตือนปรับตามอัตโนมัติ

**ทดสอบเอง:** แท็บ **Actions** → **notify-movers** → **Run workflow** แล้วเลือก mode

| mode | ส่งอะไร |
|---|---|
| `ping` | ข้อความทดสอบสั้นๆ (เช็กว่าแจ้งเตือนเข้าเครื่อง) |
| `am` | สรุปสหรัฐ |
| `noon` | สรุปหุ้นไทยพักเที่ยง |
| `pm` | สรุปเอเชีย |

ช่อง **force** (ติ๊กถูก) = ส่งทั้งที่ตลาดปิด ใช้ตอนทดสอบวันหยุด

**ลงเครื่องใหม่ให้รับแจ้งเตือน:** ติดตั้งแอป **ntfy** จาก Play Store → กด **+** → ใส่ชื่อช่อง (รหัสลับของฉัน **เก็บไว้ในอีเมล/โน้ตส่วนตัว ไม่เขียนในนี้ เพราะ repo นี้เป็นสาธารณะ**) → Subscribe → ตั้งค่าแบตเตอรี่ของแอป ntfy เป็น No restrictions / Unrestricted

**รหัสช่องที่ GitHub ใช้ส่ง:** เก็บอยู่ใน GitHub → **Settings** → **Secrets and variables** → **Actions** ชื่อ `NTFY_TOPIC`

**เปลี่ยนเวลาแจ้งเตือน หรือจำนวนที่แจ้ง:** แก้ได้แต่ค่อนข้างละเอียดอ่อน (เวลาใน `notify.yml` เป็นเวลา UTC = เวลาไทยลบ 7 ชั่วโมง และต้องแก้อีกบรรทัดให้ตรงกัน) แนะนำให้ **ขอ Claude ทำให้** (ดูข้อ 8) ส่วนจำนวนตัวที่แจ้ง คือค่า `TOP_N = 3` ในไฟล์ `notify.py`

## 5. จุดบันทึก (checkpoint) ไว้ถอยกลับ

ตอนนี้มี `checkpoint-1`, `checkpoint-2` (หลังปรับหน้าจอรอบล่าสุดแนะนำให้สร้าง `checkpoint-3`) (ดูที่ `github.com/mornavapon/stock/releases`)

**สร้างจุดใหม่ (ตอนพอใจกับหน้าตาปัจจุบัน):**
1. เปิด `https://github.com/mornavapon/stock/releases/new`
2. ช่อง **Choose a tag** พิมพ์ชื่อใหม่ เช่น `checkpoint-3` แล้วกด **Create new tag**
3. ช่อง title พิมพ์ชื่อสั้นๆ ว่าจุดนี้มีอะไร
4. กด **Publish release**

**ถอยกลับ:** บอก Claude ว่า "ถอยกลับ checkpoint-N" (Claude อ่านไฟล์จากจุดนั้นแล้วส่งให้วางทับ) หรือทำเอง: หน้าแรกของ repo → กดช่องเลือก branch (เขียนว่า `main`) → แท็บ **Tags** → เลือก checkpoint → เปิดไฟล์ที่ต้องการ → กดไอคอนคัดลอกเนื้อหา → กลับไปเลือก `main` → แก้ไฟล์เดิมแล้ววางทับ

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หุ้นตัวหนึ่งขึ้น "—" | รหัสผิดหรือ Yahoo ไม่มี ดูชื่อที่บรรทัด "ไม่พบราคา: ..." ล่างสุดของแอป แล้วแก้รหัส (ดูตารางข้อ 1) หรือเพิ่งแก้ไฟล์ รอรอบดึงราคาถัดไป |

## 7. ความปลอดภัย

- repo นี้เป็น **สาธารณะ** ใครมีลิงก์ก็เห็นรายชื่อหุ้นที่ติดตามได้ แต่แก้ไม่ได้
- **ห้ามใส่** จำนวนหุ้นที่ถือ ราคาที่ซื้อ รหัสผ่าน หรือรหัสลับใดๆ ลงในไฟล์ใน repo นี้
- GitHub เปิด 2FA แล้ว (แอป Authenticator + recovery codes ในอีเมล)
